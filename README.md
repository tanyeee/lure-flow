# ルアーアクション・シミュレータ

自作ルアーが任意の流速でどう泳ぐか（首振り・ローリング・頭下がり・引き抵抗）を、回流水槽のような条件で3D表示するWebアプリです。

公開URL: https://tanyeee.github.io/lure-flow/

## 使い方

- 流速・再生速度・ラインアイ（固定／リーダー）を変えて、泳ぎの変化を確認できます
- 1画面／2画面／3画面、2種のルアーを並べる比較表示に対応しています
- スマホではブラウザの共有メニューから「ホーム画面に追加」するとアプリとして使えます
- 設定は端末に保存されます。新しい版を公開したら、アプリ内の「アプリを更新」で切り替わります

## 更新の仕方

ルアーのデータ（sim_bundle.json）やアプリ本体は、手元の lure3d で `python3 app/build.py` を実行して作り直し、
`app/pwa/` の中身をこのリポジトリに上書きして push します。

## 注意

ボディ・リップの流体力、重力・浮力、ラインの張力から6自由度の運動を解いていますが、
リップから剥がれる渦の横力は現象論モデルで、振幅は較正係数に依存します。形状の違いによる傾向の比較に使ってください。
